# ComfyUI Workflows Collection

Welcome to my collection of free ComfyUI workflows! This repository contains various workflows I've created and shared to help the ComfyUI community.

## About

I create and share these workflows as part of my exploration into AI art and generative workflows. Each workflow is completely free to use, modify, and learn from.

I'm passionate about the open source community and want to contribute as much as I can to help others. My goal with these workflows is to make them as easily understandable as possible - that's why I love using clear lines and organized structures. I believe workflows should be approachable for everyone, from beginners to advanced users.

**Want to learn more?** Check out my blog at [apatero.com/blog](https://apatero.com/blog) where I write detailed tutorials, tips, and insights about ComfyUI, AI art, and creative workflows.

## How to Use These Workflows

1. Download the `.json` workflow file
2. Open ComfyUI
3. Drag and drop the workflow file into ComfyUI or use File → Load
4. Install any required custom nodes (see individual workflow documentation)
5. Adjust parameters and generate!
